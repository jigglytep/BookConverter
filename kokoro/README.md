# Document & Audiobook Toolkit

A toolkit for converting document OCR outputs (such as **MinerU / magic-pdf**) into **EPUB3 ebooks with full LaTeX/MathML formula support**, synthesizing clean text into **audiobooks using Kokoro-82M TTS**, and uploading both into **Audiobookshelf** as unified media items.

```
books/*.pdf  ──mineru/magic-pdf──>  Markdown + LaTeX + Images
                                       ├──>  mineru_to_epub.py  ──>  Book.epub (MathML + Images) ──┐
                                       └──>  audiobook_tts.py   ──>  Book.m4b (TTS Audio)       ──┴──>  upload_to_abs.py  ──>  Audiobookshelf
```

## MinerU to EPUB3 Converter

[`mineru_to_epub.py`](mineru_to_epub.py) converts Markdown (`.md`) and Text (`.txt`) files (generated by [MinerU (magic-pdf)](https://github.com/opendatalab/MinerU) or OCR pipelines) into compliant EPUB3 ebooks with native math typography and embedded images.

### LaTeX & MathML Processing

- **Pure Python Math Conversion**: Uses [`latex2mathml`](https://github.com/roniemartinez/latex2mathml) to convert LaTeX formulas directly into standard W3C **MathML 3** (`<math xmlns="...">`).
- **No Heavy System Dependencies**: No Pandoc, Node.js, MathJax CLI, or TeXLive installations required.
- **Native EPUB3 Reader Support**: MathML is rendered as sharp, scalable vector typography in Apple Books, Kobo, KOReader, Calibre E-book Viewer, Thorium, and Readium.
- **Markdown-Safe Tokenization**: Formulas are extracted and replaced with unique tokens before Markdown parsing, preventing underscores (`x_i`), asterisks (`a * b`), or pipe characters in math from corrupting the layout.
- **OCR Artifact Cleanup**: Automatically strips OCR artifacts like `\label{...}`, `\notag`, `\nonumber`, and cleans delimiter spacing.
- **Robust Fallback**: If an OCR-garbled formula cannot be parsed into MathML, it falls back to styled monospace text without interrupting the conversion.

### Features

- **Text & Markdown Format Support**: Supports `.md`, `.markdown`, `.txt`, and `.text` single files or folders containing multiple page/chapter files.
- **Math Support**: Inline math (`$...$`, `\(...\)`), block math (`$$...$$`, `\[...\]`), and environments (`\begin{aligned}`, `\begin{pmatrix}`, `\begin{cases}`, `\sum`, `\int`, `\frac`, etc.).
- **Automatic Image Packaging**: Automatically locates referenced images (e.g. `images/img_0.png`), packs them into the EPUB manifest with correct MIME types, and rewrites image paths.
- **Smart Chapter Splitting**: Split files into chapters by `# Heading 1` (`--split-level 1`), `## Heading 2` (`--split-level 2`), standard text chapter patterns (`Chapter 1`, `CHAPTER II`, `Prologue`), or custom regex (`--chapter-pattern`).
- **Navigation & TOC**: Generates both EPUB3 Navigation Document (`nav.xhtml`) and EPUB2 NCX (`toc.ncx`) for maximum device compatibility.
- **E-Reader Optimized Typography**: Built-in CSS with horizontal scrolling for wide equations/matrices, responsive image sizing, and styled tables.

### CLI Usage

```bash
# Convert a single MinerU markdown file to EPUB
python3 mineru_to_epub.py /path/to/mineru_output/output.md -o output.epub

# Convert a plain text file (.txt) with automatic chapter detection
python3 mineru_to_epub.py /path/to/book.txt -o book.epub

# Convert with custom chapter splitting pattern
python3 mineru_to_epub.py book.txt --chapter-pattern "^Chapter \d+"

# Convert an entire directory of text or markdown page files
python3 mineru_to_epub.py /path/to/mineru_output_dir/ \
  --title "Deep Learning & Neural Networks" \
  --author "AI Research" \
  --lang en

# Split chapters on '## Heading 2' and specify a cover image
python3 mineru_to_epub.py document.md \
  --split-level 2 \
  --cover cover.jpg \
  -o book.epub
```

#### CLI Options

| Argument | Description | Default |
|---|---|---|
| `input` | Path to `.md` / `.txt` file or directory containing document files | *Required* |
| `-o`, `--output` | Destination `.epub` path | `<input_name>.epub` |
| `-t`, `--title` | Book title | First `# Title` / `Title:` or file stem |
| `-a`, `--author` | Author metadata | `MinerU` |
| `-l`, `--lang` | Language code (e.g. `en`, `zh`, `fr`) | `en` |
| `--split-level` | Header level for chapter splitting (`1` for `#`, `2` for `##`, `0` for none) | `1` |
| `-p`, `--chapter-pattern` | Custom regex pattern to split chapters on | Auto-detect |
| `--preserve-linebreaks` | Preserve single line breaks within paragraphs as `<br>` | `False` |
| `--cover` | Path to cover image file (`.jpg`, `.png`) | `None` |
| `--css` | Path to custom CSS stylesheet | Built-in stylesheet |
| `--publisher` | Publisher metadata | `None` |
| `-v`, `--verbose` | Enable debug logging | `False` |

### Python API

```python
from mineru_to_epub import convert_mineru_to_epub

epub_file = convert_mineru_to_epub(
    input_path="mineru_output/sample.txt",
    output_epub_path="sample.epub",
    title="Advanced Linear Algebra",
    author="Professor Smith",
    language="en",
    split_level=1,
)
print(f"Created: {epub_file}")
```

## Kokoro-82M Audiobook TTS

[`audiobook_tts.py`](audiobook_tts.py) synthesizes extracted text into audiobooks using the local [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) model running in-process on GPU or CPU.

### TTS Setup & Usage

```bash
# A single text file
python3 audiobook_tts.py mybook.txt -o audiobooks/mybook.mp3

# A directory of page files
python3 audiobook_tts.py path/to/page_folder/

# Batch mode: convert all subfolders in one command
python3 audiobook_tts.py --batch path/to/books_folder/

# Customize voice, speed, and hardware acceleration
python3 audiobook_tts.py mybook.txt --voice am_michael --speed 1.05 --device cuda

# List all available voices
python3 audiobook_tts.py --list-voices

# Export one MP3 per page instead of one combined file
python3 audiobook_tts.py path/to/pages/ --per-page
```

### Picking a Voice

Kokoro includes 50+ built-in voices (`--list-voices`):
- **American English**: `af_heart` (default, top quality), `af_bella`, `am_fenrir`, `am_michael`.
- **British English**: `bf_emma`, `bm_george`.
- **Audition a voice**:
  ```bash
  head -c 2000 mybook.txt > /tmp/sample.txt
  python3 audiobook_tts.py /tmp/sample.txt --voice af_heart -o /tmp/af_heart.mp3
  ```

### TTS Configuration Defaults (`config.py`)

| Setting | Default | Description |
|---|---|---|
| `VOICE` | `af_heart` | Default narration voice |
| `LANG_CODE` | `None` (auto) | Inferred from voice prefix |
| `SPEED` | `1.0` | Natural speaking rate multiplier |
| `DEVICE` | `None` (auto) | CUDA if available, else CPU |
| `CHUNK_SIZE_WORDS` | `500` | Word count per synthesis chunk |
| `AUDIO_FORMAT` / `AUDIO_BITRATE` | `mp3` / `192k` | Spoken audio format and bitrate |

## Audiobookshelf Uploader

[`upload_to_abs.py`](upload_to_abs.py) uploads audiobooks (`.m4b`, `.mp3`) and companion ebooks (`.epub`) to a self-hosted [AudioBookshelf](https://www.audiobookshelf.org/) server.

### Audio + EPUB Multi-File Ingestion

When both an audio file and an EPUB file are uploaded together, Audiobookshelf stores them in the **same book directory**. This creates a single library item with both audio playback and e-reader capabilities synced across devices.

- **Auto-Detection**: If you pass `book.m4b`, the script automatically detects and includes `book.epub` if present in the same or parent directories.
- **Explicit EPUB**: Pass `--epub /path/to/book.epub` to explicitly choose a companion file.
- **Audio Only**: Pass `--no-epub` to skip auto-detecting/uploading an EPUB.

### Uploader CLI Usage

```bash
# 1. Upload audio with automatic companion EPUB detection
python3 upload_to_abs.py audiobooks/Book.m4b \
  --title "Book Title" \
  --author "Author Name" \
  --scan

# 2. Upload with explicit companion EPUB path
python3 upload_to_abs.py audiobooks/Book.m4b \
  --epub out/Book/Book.epub \
  --title "Book Title" \
  --author "Author Name"

# 3. Custom server and authentication
python3 upload_to_abs.py audiobooks/Book.m4b \
  --server http://localhost:3378 \
  --token YOUR_API_TOKEN \
  --library "Audiobooks"
```

#### Options

| Argument | Description | Default |
|---|---|---|
| `file` | Audiobook file (`.m4b`, `.mp3`) or ebook (`.epub`) | *Required* |
| `--epub` | Path to companion `.epub` file | Auto-detected |
| `--no-epub` | Disable automatic EPUB detection | `False` |
| `--server` | Audiobookshelf server URL (or `ABS_SERVER` in `.env`) | `http://localhost:3378` |
| `--token` | API token (Settings -> Users -> account, or `ABS_TOKEN`) | `None` |
| `--username` | Account username (if not using token, or `ABS_USERNAME`) | `""` |
| `--password` | Account password (if not using token, or `ABS_PASSWORD`) | `""` |
| `--library` | Target library name or ID | First book library |
| `--folder` | Target folder ID | First folder in library |
| `--title` | Book title | File stem |
| `--author` | Author metadata | `""` |
| `--series` | Series metadata | `""` |
| `--scan` | Trigger library re-scan after upload | `False` |

## Installation & Requirements

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. System Packages

```bash
# ffmpeg for audio encoding, espeak-ng for TTS phonemizer fallback
sudo apt-get update
sudo apt-get install -y ffmpeg espeak-ng
```
